# Mini-Quant-Lab-Project-Series

Welcome to my Mini Quant Lab!!!

This repository serves as a portfolio of bite-sized quantitative projects where I experiment with analytical techniques, statistical methods, simulations, and data visualization.

The goal is simple:
- Learn one concept at a time.
- Build practical projects.
- Document the process.
- Continuously improve.

## Repository Structure

Each project includes:

- 📂 Source files
- 📊 Final outputs
- 📝 Project notes
- 📈 Methodology
- 💡 Key takeaways

## Why this repository?

I believe technical skills are best developed through consistent practice. Rather than waiting for large, polished projects, this repository documents continuous learning through focused mini-projects that explore quantitative techniques applicable to economics, finance, and data analysis.
